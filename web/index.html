How it works

Each step is small enough to test and explain.

01 · Ingest

Check CSV columns and join on the original job ID.

02 · Retrieve

Exact ID lookup first, then SQLite FTS5 full-text matching.

03 · Generate

Use real source values, optionally selected by a local LLM.

04 · Verify

Accept only claims that match allowed field-value pairs.

05 · Evaluate

Compare baseline and guardrails on the same generated benchmark.

What the dataset cannot answer

Company names, job titles, locations, full descriptions, expanded skill-code names, and industry-code meanings are missing. The guarded system should refuse to invent these.

Why this matters

An FDE must explain not only what the demo can do, but where the data ends and how to detect failures.
